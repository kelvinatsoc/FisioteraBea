# FisioBea 💚💛

Site pessoal da Beatriz para planejar atendimentos de fisioterapia.

## Funcionalidades
- **Agenda** da semana (segunda a sábado) com os pacientes de cada dia e o treino que cai naquela sessão.
- **Pacientes**: nome, diagnóstico, dias de atendimento (ex.: seg/qua/sex), horário.
- **Treinos A, B, C, D…** por paciente, com exercícios, séries, repetições, carga e observações. Os treinos giram automaticamente a cada sessão.
- **Evoluções** a partir de um modelo pronto: é só preencher. Os exercícios do treino do dia já entram preenchidos na conduta. Botão para copiar o texto.
- **Modelo de evolução** editável (adicionar, remover e reordenar campos).
- **Backup**: baixar e restaurar os dados em arquivo `.json`.

## Como usar
Abra o arquivo `index.html` no navegador. Não precisa instalar nada.
Os dados ficam salvos no próprio navegador, então faça backup com frequência (aba **Modelo → Baixar backup**).
